# ArduCopter 日志任务调度详解与如何添加新日志

---

## 一、日志任务调度代码分析

```cpp
#if HAL_LOGGING_ENABLED
    FAST_TASK(Log_Video_Stabilisation),                              // 1?? 高频
    SCHED_TASK(loop_rate_logging, LOOP_RATE, 50, 75),               // 2?? 循环频率
    SCHED_TASK(ten_hz_logging_loop, 10, 350, 114),                  // 3?? 10Hz
    SCHED_TASK(twentyfive_hz_logging, 25, 110, 117),                // 4?? 25Hz
    SCHED_TASK_CLASS(AP_Logger, &copter.logger, periodic_tasks, 400, 300, 120),  // 5?? 400Hz
    SCHED_TASK_CLASS(AP_Scheduler, &copter.scheduler, update_logging, 0.1, 75, 126), // 6?? 0.1Hz
#endif
```

### 参数说明

每个任务的格式为：`SCHED_TASK(函数名, 频率(Hz), 最大执行时间(μs), 优先级)`

| 参数 | 说明 |
|------|------|
| **函数名** | 要执行的日志记录函数 |
| **频率(Hz)** | 每秒执行多少次（LOOP_RATE=主循环频率，通常400Hz） |
| **最大执行时间(μs)** | 预计该任务最长需要多少微秒 |
| **优先级** | 0-255，值越小优先级越高 |

## 二、六个日志任务详解

### 1?? Log_Video_Stabilisation (高频任务)

**调用频率：** 主循环频率（~400Hz）  
**执行时间：** 极短  
**记录内容：** 视频稳定化相关数据（仅用于带云台的设备）

```cpp
void Copter::Log_Video_Stabilisation() {
    if (!should_log(MASK_LOG_VIDEO_STABILISATION)) {
        return;  // 如果未启用此日志类型，直接返回
    }
    ahrs.write_video_stabilisation();  // 写入AHRS的视频稳定化数据
}
```

**记录的数据：**
- 云台目标姿态
- 实时姿态偏差
- 稳定化补偿值

---

### 2?? loop_rate_logging (循环频率日志)

**调用频率：** LOOP_RATE（主控制循环频率）  
**执行时间：** 50 μs  
**优先级：** 75  
**记录内容：** 最快速的姿态和PID数据

```cpp
void Copter::loop_rate_logging() {
    // ========== 姿态和PID日志 ==========
    if (should_log(MASK_LOG_ATTITUDE_FAST) &&
        !copter.flightmode->logs_attitude()) {
        Log_Write_Attitude();    // 写入姿态数据（滚转、俯仰、偏航）
        Log_Write_PIDS();        // 写入PID数据（P/I/D值、误差等）
    }
    
    // ========== 谐波陷波数据 ==========
    if (should_log(MASK_LOG_FTN_FAST)) {
        AP::ins().write_notch_log_messages();  // 谐波陷波过滤器的日志
    }
    
    // ========== IMU快速数据 ==========
    if (should_log(MASK_LOG_IMU_FAST)) {
        AP::ins().Write_IMU();   // IMU的快速采样数据（加速度、角速度）
    }
}
```

**记录的数据：**
```
? 姿态：Roll、Pitch、Yaw
? PID：P值、I值、D值、目标值、实际值、误差
? IMU：加速度(XYZ)、角速度(XYZ)、每项频率~400Hz
? 谐波陷波：滤波器状态、中心频率、衰减值
```

### 3?? ten_hz_logging_loop (10Hz日志)

**调用频率：** 10Hz  
**执行时间：** 350 μs  
**优先级：** 114（较低）  
**记录内容：** 综合传感器和控制数据

```cpp
void Copter::ten_hz_logging_loop() {
    // ========== 条件1：中等速率的姿态日志 ==========
    if (should_log(MASK_LOG_ATTITUDE_MED) &&
        !should_log(MASK_LOG_ATTITUDE_FAST) &&    // 避免重复记录
        !copter.flightmode->logs_attitude()) {
        Log_Write_Attitude();
    }
    
    // ========== 条件2：PID日志（备选） ==========
    if (!should_log(MASK_LOG_ATTITUDE_FAST) &&
        !copter.flightmode->logs_attitude()) {
        Log_Write_PIDS();   // 如果没有快速PID日志，在10Hz记录
    }
    
    // ========== 条件3：EKF位置数据 ==========
    if (!should_log(MASK_LOG_ATTITUDE_FAST)) {
        Log_Write_EKF_POS();   // EKF估算的位置、速度、偏差
    }
    
    // ========== 条件4：电机和电池数据 ==========
    if (should_log(MASK_LOG_MOTBATT)) {
        motors->Log_Write();   // 电机输出、转速、电压等
    }
    
    // ========== 条件5：遥控输入 ==========
    if (should_log(MASK_LOG_RCIN)) {
        logger.Write_RCIN();   // RC信道原始数据
        if (rssi.enabled()) {
            logger.Write_RSSI();   // 信号强度
        }
    }
    
    // ========== 条件6：遥控输出 ==========
    if (should_log(MASK_LOG_RCOUT)) {
        logger.Write_RCOUT();  // PWM输出信号
    }
    
    // ========== 条件7：导航调谐数据 ==========
    if (should_log(MASK_LOG_NTUN) &&
        (flightmode->requires_GPS() || landing_with_GPS() ||
         !flightmode->has_manual_throttle())) {
        pos_control->write_log();   // 位置、速度、加速度目标值
    }
    
    // ========== 条件8：振动数据 ==========
    if (should_log(MASK_LOG_IMU) || should_log(MASK_LOG_IMU_FAST) ||
        should_log(MASK_LOG_IMU_RAW)) {
        AP::ins().Write_Vibration();  // IMU振动水平（震动严重度）
    }
    
    // ========== 条件9：控制调谐数据 ==========
    if (should_log(MASK_LOG_CTUN)) {
        attitude_control->control_monitor_log();  // 油门、高度、爬升率
        // 以下是可选的附加传感器
#if HAL_PROXIMITY_ENABLED
        g2.proximity.log();    // 测距传感器距离
#endif
#if AP_BEACON_ENABLED
        g2.beacon.log();       // 信标数据
#endif
    }
    
    // ========== 直升机特定日志 ==========
#if FRAME_CONFIG == HELI_FRAME
    Log_Write_Heli();          // 旋翼速度、控制混合信息
#endif
    
    // ========== 绞盘日志 ==========
#if AP_WINCH_ENABLED
    if (should_log(MASK_LOG_ANY)) {
        g2.winch.write_log();   // 绞盘高度、速度
    }
#endif
    
    // ========== 相机云台日志 ==========
#if HAL_MOUNT_ENABLED
    if (should_log(MASK_LOG_CAMERA)) {
        camera_mount.write_log();   // 云台角度、模式
    }
#endif
}
```

**记录的关键数据：**
```
? 姿态：Roll、Pitch、Yaw（中等精度）
? EKF：位置、速度、加速度估计值
? 电机：PWM输出、转速（如果有转速计）
? RC输入/输出：所有通道的值
? 导航：目标位置、速度、加速度
? 振动：XYZ三轴震动水平
? 控制：油门、高度、爬升率
? 可选：云台、绞盘、信标、测距仪
```

### 4?? twentyfive_hz_logging (25Hz日志)

**调用频率：** 25Hz  
**执行时间：** 110 μs  
**优先级：** 117  
**记录内容：** EKF和谐波陷波日志

```cpp
void Copter::twentyfive_hz_logging() {
    // ========== EKF日志 ==========
    if (should_log(MASK_LOG_ATTITUDE_FAST)) {
        Log_Write_EKF_POS();   // 当快速姿态日志启用时，在25Hz记录EKF
    }
    
    // ========== IMU日志（条件）==========
    if (should_log(MASK_LOG_IMU) && !(should_log(MASK_LOG_IMU_FAST))) {
        AP::ins().Write_IMU();  // 如果未启用快速IMU日志，在25Hz记录
    }
    
    // ========== 自动旋转日志（直升机） ==========
#if MODE_AUTOROTATE_ENABLED == ENABLED
    if (should_log(MASK_LOG_ATTITUDE_MED) ||
        should_log(MASK_LOG_ATTITUDE_FAST)) {
        g2.arot.Log_Write_Autorotation();   // 自动旋转模式数据
    }
#endif
    
    // ========== 陀螺仪FFT日志 ==========
#if HAL_GYROFFT_ENABLED
    if (should_log(MASK_LOG_FTN_FAST)) {
        gyro_fft.write_log_messages();   // 频域分析数据
    }
#endif
}
```

**记录的数据：**
```
? EKF位置/速度（25Hz采样）
? IMU原始数据（如果未用快速采样）
? 自动旋转状态（直升机）
? 陀螺仪FFT频谱数据（用于调谐）
```

---

### 5?? AP_Logger::periodic_tasks (400Hz日志管理)

**调用频率：** 400Hz  
**执行时间：** 300 μs  
**优先级：** 120  
**作用：** 日志系统的核心管理任务

```cpp
// 这是 AP_Logger 类的方法
// 作用：处理日志缓冲区、SD卡写入等底层操作
logger.periodic_tasks();
```

**具体做的事：**
```
? 处理日志写缓冲区（将缓冲区数据写到SD卡）
? 检查SD卡状态
? 管理日志文件循环（当日志文件过大时）
? 处理日志写入超时
? 监控可用存储空间
```

---

### 6?? AP_Scheduler::update_logging (0.1Hz日志调试)

**调用频率：** 0.1Hz（每10秒1次）  
**执行时间：** 75 μs  
**优先级：** 126（最低）  
**作用：** 监控日志系统健康状况

```cpp
// 这是任务调度器的日志更新方法
scheduler.update_logging();
```

**具体做的事：**
```
? 记录任务执行时间统计
? 检测任务超时
? 更新日志状态消息
? 监控系统负载
```

## 三、日志记录的完整流程

```
用户配置 LOG_BITMASK
  ↓
任务调度器在指定频率调用日志函数
  ↓
should_log(MASK_XXX) 检查是否应该记录该类型日志
  ↓
Log_Write_XXX() 函数填充数据结构体
  ↓
logger.WriteBlock() 写入缓冲区
  ↓
AP_Logger::periodic_tasks() 定期刷新到SD卡
  ↓
SD卡保存 .bin 日志文件
```

## 四、如何添加新的日志

### 方法1：在现有日志函数中添加新数据

**场景：** 要在10Hz日志中记录一个新的传感器数据

**步骤：**

#### Step 1: 在 Log.cpp 中定义日志结构体

```cpp
// Log.cpp 顶部添加新结构体
struct PACKED log_MyCustomData {
    LOG_PACKET_HEADER;
    uint64_t time_us;
    float    custom_value1;
    float    custom_value2;
    int16_t  custom_value3;
};
```

#### Step 2: 创建写日志的函数

```cpp
// Log.cpp 中添加
void Copter::Log_Write_CustomData() {
    struct log_MyCustomData pkt = {
        LOG_PACKET_HEADER_INIT(LOG_CUSTOM_DATA_MSG),  // 需要定义消息ID
        time_us      : AP_HAL::micros64(),
        custom_value1: get_sensor_reading_1(),
        custom_value2: get_sensor_reading_2(),
        custom_value3: (int16_t)get_sensor_reading_3()
    };
    logger.WriteBlock(&pkt, sizeof(pkt));
}
```

#### Step 3: 在日志结构数组中注册

```cpp
// Log.cpp 中的 log_structure[] 数组添加
{ 
    LOG_CUSTOM_DATA_MSG,           // 消息ID
    sizeof(log_MyCustomData),      // 大小
    "CDAT",                         // 4字符名称（在Mission Planner显示）
    "Qffi",                         // 数据类型：Q=uint64, f=float, i=int32
    "TimeUS,Val1,Val2,Val3",        // 字段名
    "s---",                         // 单位（s=秒, -=无）
    "F---"                          // 精度（F=64位float）
    , true                          // 日志优先级
},
```

#### Step 4: 在日志任务中调用

选择合适的频率：

**Option A：在 ten_hz_logging_loop() 中添加（推荐）**
```cpp
void Copter::ten_hz_logging_loop() {
    // 现有代码...
    
    // 添加新日志
    if (should_log(MASK_LOG_ANY)) {  // 或者定义新的MASK_LOG_CUSTOM
        Log_Write_CustomData();
    }
}
```

**Option B：创建新的日志任务（适合高频数据）**
```cpp
// Copter.cpp 中添加函数声明（在 Copter.h 中）
void log_custom_loop();

// Copter.cpp 中实现
void Copter::log_custom_loop() {
    if (should_log(MASK_LOG_CUSTOM)) {
        Log_Write_CustomData();
    }
}

// 在 scheduler_tasks[] 中添加
SCHED_TASK(log_custom_loop, 100, 100, 119),  // 100Hz, 100μs, 优先级119
```

### 方法2：完整示例 - 添加测距仪高度日志

假设你要记录测距仪高度，频率为10Hz。

**第1步：定义结构体（Log.cpp 顶部）**
```cpp
struct PACKED log_Rangefinder_Height {
    LOG_PACKET_HEADER;
    uint64_t time_us;
    float    rangefinder_height_m;
    uint8_t  rangefinder_status;
};
```

**第2步：创建日志函数（Log.cpp）**
```cpp
void Copter::Log_Write_Rangefinder_Height() {
    struct log_Rangefinder_Height pkt = {
        LOG_PACKET_HEADER_INIT(LOG_RANGEFINDER_HEIGHT_MSG),
        time_us                : AP_HAL::micros64(),
        rangefinder_height_m   : rangefinder.distance_m(),
        rangefinder_status     : (uint8_t)rangefinder.status()
    };
    logger.WriteBlock(&pkt, sizeof(pkt));
}
```

**第3步：在 log_structure[] 中注册（Log.cpp）**
```cpp
{ 
    LOG_RANGEFINDER_HEIGHT_MSG,
    sizeof(log_Rangefinder_Height),
    "RNG",
    "Qfb",
    "TimeUS,Height,Status",
    "sm-",
    "F--"
    , true
},
```

**第4步：在 ten_hz_logging_loop() 中调用（Copter.cpp）**
```cpp
if (should_log(MASK_LOG_RANGEFINDER)) {
    Log_Write_Rangefinder_Height();
}
```

**第5步：定义日志掩码（defines.h 或 config.h）**
```cpp
#define MASK_LOG_RANGEFINDER (1 << 25)  // 选择一个未使用的位
```

### 方法3：通用日志接口（最简单）

如果只是想快速记录单个数据，可以用通用接口：

```cpp
// 在任何地方使用

                    "Qf",
                    AP_HAL::micros64(),
```

## 六、添加新日志的检查清单

```
□ 1. 定义日志结构体（struct PACKED）
     └─ 包含 LOG_PACKET_HEADER
     └─ 第一个字段必须是 uint64_t time_us

□ 2. 创建 Log_Write_XXX() 函数
     └─ 收集数据
     └─ 填充结构体
     └─ 调用 logger.WriteBlock()

□ 3. 在 log_structure[] 中注册
     └─ 消息类型ID（LOG_XXX_MSG）
     └─ 大小（sizeof()）
     └─ 名称（4字符）
     └─ 数据类型字符串
     └─ 字段名称
     └─ 单位
     └─ 精度

□ 4. 定义日志掩码（可选）
     └─ 在 defines.h 中添加 MASK_LOG_XXX

□ 5. 在合适的日志任务中调用
     └─ loop_rate_logging()   - 主循环频率（快速）
     └─ ten_hz_logging_loop() - 10Hz（推荐）
     └─ twentyfive_hz_logging() - 25Hz
     └─ 或创建新的日志任务

□ 6. 编译测试
     └─ 运行编译检查
     └─ 使用 Mission Planner 检查日志
```

## 总结

| 任务 | 频率 | 主要数据 | 何时使用 |
|------|------|---------|--------|
| Log_Video_Stabilisation | 400Hz | 云台稳定化 | 有云台设备 |
| loop_rate_logging | 400Hz | 姿态、PID、IMU | 快速控制调试 |
| ten_hz_logging_loop | 10Hz | **综合数据** | 普通应用（推荐） |
| twentyfive_hz_logging | 25Hz | EKF、FFT | 导航/谐波调试 |
| periodic_tasks | 400Hz | 缓冲区管理 | 自动 |
| update_logging | 0.1Hz | 性能统计 | 自动 |

**建议：** 大多数情况下，在 `ten_hz_logging_loop()` 中添加新日志是最合理的选择！
